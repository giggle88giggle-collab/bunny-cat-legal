Privacy Policy

Effective date: 22 October 2026. Operator: the owner of the Bunny & Cat YouTube channel ("we").

1. What this app does

Bunny & Cat is a private automation tool. It creates short educational videos and uploads them to the owner's own YouTube channel. Uploads are set to private. The owner decides separately whether any video is made public.

2. Google user data we access

The owner signs in with Google and grants two permissions (OAuth scopes):

  • https://www.googleapis.com/auth/youtube.upload – to upload videos to the owner's channel.
  • https://www.googleapis.com/auth/youtube.readonly – to read back the status of uploaded videos and confirm they are private.

We store a refresh token that lets the tool obtain short-lived access tokens without asking the owner to sign in again. Access tokens are used only for the request in which they are obtained and are not stored.

3. How data is stored and protected

  • The refresh token is encrypted with a key kept separately. The encrypted token and key are stored as encrypted secrets in the owner's private GitHub repository settings. They are never published, shared in chat, or written into code or logs.
  • The publish log records, for each video, the title, the episode name, the upload result, and the YouTube video ID and link. It is kept in the owner's private repository.
  • No refresh token or access token is sent to a web browser.

4. How we use the data

We use Google user data only to upload and verify videos on the owner's own channel, and to show the owner the upload status and any reconnection message. We do not sell Google user data. We do not use it for advertising, profiling, or training AI or machine-learning models. We do not share it with third parties except as described in section 6.

Use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

5. Children

The channel makes content for young children. This tool does not collect personal information from viewers or from children. It does not use cookies, analytics or advertising on this website.

6. Third-party services

  • Google / YouTube – authorization and video uploads. Governed by Google's privacy policy.
  • GitHub – hosts the code, runs the scheduled jobs, and stores the encrypted secrets.
  • Microsoft Edge text-to-speech – the narration script text is sent to Microsoft's speech service to create voice audio. No Google user data is sent to it.

7. Retention and deletion

  • The refresh token is kept until the owner revokes it or deletes the stored secret.
  • To remove the app's access, the owner can go to myaccount.google.com/permissions and remove "Bunny & Cat", and delete the GitHub secrets. Access then stops immediately.
  • Uploaded videos stay on YouTube until the owner removes them there.

8. Your choices

You can revoke access at any time (see section 7), or ask questions by opening an issue at github.com/giggle88giggle-collab/bunny-cat-legal/issues.

9. Changes

If this policy changes, the new version is posted on this page with a new effective date.
